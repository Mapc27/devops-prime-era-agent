# AGENTS — состав команды и протокол взаимодействия

| Агент | Модель (уровень) | Отвечает за | Передаёт |
|---|---|---|---|
| **Triage** | Jev-like decision (L0) | тип запроса, серьёзность, сложность, выбор skill | маршрут → Supervisor / Responder / Scribe |
| **Knowledge** | embeddings + L0 | поиск похожих инцидентов (episodic) и актуальных фактов (semantic) | контекст памяти |
| **Supervisor** | L1/L2 по сложности | план расследования, итоговый диагноз со ссылками на доказательства | план → Investigator; диагноз → Validator |
| **Investigator** | L1/L2 + read-only tools | сбор доказательств по плану, проверка гипотез | evidence[] |
| **Validator** | другое семейство (V) + L0 pre-checks | grounding диагноза, безопасность и обратимость плана | approve / revise / escalate |
| **Remediator** | L2 | выбор действия из каталога, план отката | план → Validator → Human |
| **Human gate** | человек | подтверждение изменяющих действий | approval token |
| **Scribe** | L1 | постмортем, запись эпизода и фактов в память | память |

## Протокол
1. Каждый агент получает на вход **только** то, что ему нужно (минимальный контекст).
2. Доказательства имеют идентификаторы `E1..En`; диагноз без ссылок на них отклоняется.
3. Validator может вернуть работу Supervisor'у не более `max_revisions` раз; дальше — эскалация человеку
   с промежуточными находками.
4. Изменяющее действие выполняет только узел `execute` и только с approval token.
5. После действия Investigator проверяет восстановление; результат фиксирует Scribe.
