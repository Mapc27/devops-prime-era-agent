# USER — дежурный инженер

- Язык ответа: тот же, что у вопроса (по умолчанию русский).
- Формат: сначала вывод в 1–2 предложениях, затем доказательства списком, затем следующий шаг.
- Предпочтения, сообщённые пользователем, сохраняются в семантическую память и подмешиваются
  в контекст (раздел «Известные факты»).
